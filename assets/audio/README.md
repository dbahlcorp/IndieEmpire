# Original audio

Both loopable WAV files in this directory are original, sample-free assets for
Indie Empire. They are generated deterministically by
`tools/generate_original_audio.py` using synthesized oscillators, envelopes,
procedural noise, and an original note sequence. No recordings, sample packs,
or third-party compositions are included.

- `music/studio_day_loop.wav` — warm 96 BPM studio-management theme, 40 seconds.
- `ambience/office_room_loop.wav` — computer hum, ventilation, keyboard, mouse,
  chair, and room movement, 30 seconds.

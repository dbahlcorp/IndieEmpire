# Original audio

Both loopable WAV files in this directory are original, sample-free assets for
Indie Empire. They are generated deterministically by
`tools/generate_original_audio.py` using synthesized oscillators, envelopes,
procedural noise, and an original note sequence. No recordings, sample packs,
or third-party compositions are included.

- `music/studio_day_loop.wav` — warm 96 BPM studio-management theme, 40 seconds.
- `ambience/office_room_loop.wav` — computer hum, ventilation, keyboard, mouse,
  chair, and room movement, 30 seconds.

## PA.8 feedback library

`sfx/` contains 19 short, original cues generated by the same script. They
cover taps/navigation, money, research/technology, staffing, releases/reviews,
sales milestones, awards, warnings, financial crisis, and bankruptcy. The
files are final-safe synthesized placeholders: no copyrighted music, samples,
recordings, or third-party packs are present.

## Music state placeholders

`AudioManager` supports `main_menu`, `studio`, `development`,
`release_results`, `awards`, and `financial_danger`. Until additional original
or properly licensed tracks are commissioned, every state deliberately points
to `studio_day_loop.wav`. State changes are still observable and tested, while
the stream identity guard prevents navigation from restarting the shared loop.

Office ambience uses the same room loop at a scale appropriate to the current
office tier. On iOS the project uses the Ambient audio-session category and
mixes with other audio, respecting the device silent switch. Optional haptics
are limited to major confirmations, review reveals, and major achievements.

Regenerate all assets with `tools/generate_original_audio.py`; the output is
deterministic.

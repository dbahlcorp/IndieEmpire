## Final generation prompts

### App icon

> Use case: logo-brand. Asset type: production-ready 1024x1024 mobile game app icon source artwork. Create an original app icon for a cozy game development studio management game named Indie Empire. Show one charming isometric vintage computer workstation on a compact warm-wood desk. On the teal monitor screen is a simple glowing upward pixel-star/spark motif that suggests a tiny indie studio growing into an empire. Add a subtle golden desk-lamp arc or small architectural shape behind the monitor to give the silhouette ambition, but do not use a literal royal crown. Visual style: premium hand-painted 2.5D casual management game art, chunky readable shapes, lightly textured surfaces, warm and inviting, polished like a top-tier mobile tycoon game while remaining entirely original. Match a cozy illustrated isometric office with deep desaturated teal outlines, creamy highlights, honey and amber lighting, warm walnut wood, and one restrained coral accent. Composition: one centered bold emblem, strong silhouette readable at 60px, full-bleed square background, important content inside the central 80% safe area. No baked rounded corners, no frame, no border, no transparent corners. Strict constraints: no words, no letters, no numbers, no watermark, no people, no photorealism, no reference to or imitation of any existing game logo or copyrighted character.

### Logo

Create the official wordmark for the mobile game INDIE EMPIRE, using the referenced app-icon artwork only as the visual identity reference. The exact visible text must be INDIE / EMPIRE and no other text. Typography: custom chunky hand-crafted display lettering, friendly and confident, lightly beveled with subtle stepped/pixel-cut corners but not a pixel font. Make INDIE smaller, centered above the much larger EMPIRE. Deep desaturated teal letter faces, warm cream inner highlight, honey-gold dimensional edge/shadow, tiny restrained coral accent. Integrate a small simplified version of the icon's upward star-over-bars motif above or between the words; keep it clean and readable. Composition: compact wide lockup around 2.2:1, centered with generous transparent padding, crisp silhouette that remains legible at phone-menu size. Entire background must be transparent; no rectangle, scene, badge, glow cloud, frame, mockup, or colored backdrop. Strict constraints: spell INDIE EMPIRE exactly, no extra letters, no subtitle, no trademark symbol, no watermark, no imitation of any existing game logo. Entirely original premium cozy management-game branding.

### Splash

> Use case: stylized-concept / mobile game splash. Asset type: production-ready portrait splash-screen illustration for iPhone, approximately 9:19.5 composition with generous vertical crop-safe bleed. Create an original launch splash for Indie Empire using the two referenced brand assets as exact identity references. The scene is a cozy small indie game studio at golden-hour dawn, seen in a clean elevated isometric view: one inviting vintage computer workstation glowing teal, warm walnut desk, desk lamp, plant, coffee mug, a few game-design notes, and subtle stacked shapes in the distant wall that echo a growing city/empire. It should feel like the first humble office with huge potential. Place the supplied INDIE EMPIRE logo faithfully and clearly in the upper-middle portion, centered. Preserve the exact spelling and recognizable teal/cream/gold treatment. Below it, the office scene leads the eye downward. Leave calm negative space around the logo and keep all key elements inside the central 75% width so the artwork survives different iPhone crops and safe areas. Visual style: premium hand-painted 2.5D casual management-game illustration, chunky clean shapes, tactile soft textures, cozy and optimistic, deep desaturated teal shadows, warm cream, honey-gold illumination, walnut wood, restrained coral highlights. Strong visual consistency with the references, fully original. Strict constraints: portrait orientation, only the exact title INDIE EMPIRE, no subtitle, no loading bar, no buttons, no people, no watermark, no device mockup, no UI panels, no imitation of any existing game art.
